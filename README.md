### ALGO-000041: Arithmetic circuits versus branching programs
- **Subfield:** Algebraic complexity and polynomial identity testing
- **Open:** Determine whether every polynomial-size, polynomial-degree arithmetic circuit can be simulated by a polynomial-size algebraic branching program: VP = VBP.
- **Status:** Open for decades. Quasipolynomial simulations and strong results for restricted models do not establish polynomial equivalence.
- **Type:** theory
- **Why:** Measures the computational value of general arithmetic circuit structure beyond iterated linear-algebraic computation.
- **Key works:** Valiant, Skyum, Berkowitz, and Rackoff (1983), *Fast Parallel Computation of Polynomials Using Few Processors*; Shpilka–Yehudayoff survey.
- **Related:** Symbolic mathematics—efficient representation of polynomial computations.
